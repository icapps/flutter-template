**Why this size?** 

The Sentry filter is wired into all four flavor entrypoints (`main`, `main_alpha`, `main_beta`, `main_prod`) The `SentryEventFilter` is registered in `lib/di`, and it decides which events reach Sentry in production. 

Therefore specific filter events are created. So we can determine if a background or foreground event is triggered. If an event matches one of the rules we can drop it. So it doesn't reach Sentry.
